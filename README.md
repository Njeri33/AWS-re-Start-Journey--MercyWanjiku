# ☁️ AWS re/Start — My Cloud Journey (Weeks 1–5)

Documenting my path through AWS re/Start, one broken security group and one debugged Caesar cipher at a time.

Every week gets the same format, because consistency is the one thing my code doesn't have yet:

> **Task → What I Did → What I Learned → What Went Wrong → How I Solved It**

The goal isn't just to prove I finished the labs — it's to build a real trail of decision-making, mistakes, and fixes that future-me (and maybe future-you) can actually learn from.
